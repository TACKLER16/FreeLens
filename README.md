FreeLens ---
I made this project because I wanted to make Google Lens of my own, at first, i set up an opencv, then connected it with gemini api, it is still applicable in this project, you just gotta paste your API in jarvis.py.
But then, I had an idea, what if, I make it local? No API tension, efficient, but low hardware strain on my pc/laptop, that's where Ollama's model Moondream comes in.
Sadly, this project only works on laptops and pc's webcam, not on phones, I'm actively finding a way to deploy it on my phone without obliterating either of my devices.
